HOV Global Travel mascot - website preloader
============================================

Files here are generated by seo-migration\make-mascot.ps1 from
seo-migration\mascot-source\hov-global-travel-mascot.png (the approved
1536 x 1024 transparent PNG):

    hov-mascot.png        1200 px wide, alpha preserved  (fallback <img src>)
    hov-mascot.webp       same pixels, WebP               (<source> 1200w)
    hov-mascot-900.webp   900 px wide, WebP               (<source> 900w)
    hov-mascot-640.webp   640 px wide, WebP               (<source> 640w)

The artwork is trimmed to its bounding box, resampled in premultiplied
alpha, never enlarged. Nothing is cropped out of the illustration.

To replace the mascot: drop the new transparent PNG over the source file,
then from the project folder run

    .\HOV\seo-migration\make-mascot.ps1
    .\HOV\seo-migration\one-off\add-preloader.ps1 -Refresh
    .\HOV\seo-migration\build-deploy.ps1

Preview the loader in a browser at any time by opening a page with
?hov-pl=hold on the URL (click the loader to dismiss it), or ?hov-pl=play
to watch one normal run even if it has already played this session.
